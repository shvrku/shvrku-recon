## Overview

Mono is a variable type system with an engine that previews optical sizes the way a compositor would — not as a dropdown of static styles.

## Focus areas

- Variable axes with sane defaults for UI density
- Specimen pages that stress-test rhythm and spacing
- Motion that sells weight changes without spectacle

## Outcome

Type became a system you could ship, not a folder of files nobody opened.
